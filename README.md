# NeuroAssist — нейроадаптивный интерфейс корпоративного смартфона

Учебный прототип: воспроизведение реальных ЭЭГ-записей (покой / устный счёт), классификация с помощью Random Forest, WebSocket-передача прогноза и демонстрация адаптивного интерфейса в Unity.

## Требования

- **Windows 10/11**, **Unity Editor 6000.6.0f1** (через Unity Hub; первое открытие потребует установки пакетов Unity).
- **Python 3.12 рекомендован** (на другой версии может потребоваться проверка совместимости сохранённой модели).
- Интернет нужен при **первой установке** Python-библиотек и Unity-пакетов; сам WebSocket работает локально.

## Установка и запуск

1. Скачайте ZIP репозитория и распакуйте, например в `D:\NeuroAssist` (не запускайте изнутри архива).
2. Выполните **`SETUP_WINDOWS.bat`** *один раз* — создаёт `PythonServer/.venv`, устанавливает библиотеки.
3. Запустите **`START_SERVER.bat`** и оставьте окно открытым.
4. Unity Hub → **Add project from disk** → выберите папку **`UnityProject`** → откройте в Unity 6000.6.0f1.
5. В Unity откройте сцену **`Assets/NeuroAssist_Demo.unity`** (она уже включена в список сцен сборки), затем выберите NeuroAssist → Sharpness → Use native Game View resolution → **Play**. Меню `NeuroAssist → Create demo scene` использовать не требуется.
6. В панели Unity наблюдайте вероятность класса `arithmetic`, режим интерфейса, ручное включение полного режима и возврат к автоматике.

Если Unity сначала импортирует пакеты, подождите завершения импорта. Не копируйте вручную папки `Assets` между проектами.

## Структура

- `UnityProject/Assets/NeuroAssist/Scripts/NeuroAssistClient.cs` — WebSocket-клиент и гистерезис; `NeuroAssistUI.cs` — отдельный слой пользовательского интерфейса.
- `UnityProject/Assets/NeuroAssist/Resources/` — стили UI Toolkit, тема, иконки и фоновая графика. Приложения интерактивные демонстрационные экраны, не настоящие функции ОС.
- `UnityProject/Assets/NeuroAssist_Demo.unity` — сохранённая сцена.
- `PythonServer/data/demo/` — два фрагмента реальных ЭЭГ в формате EDF.
- `PythonServer/outputs/nemar_real/model.joblib` — сохранённый Random Forest.
- `PythonServer/neuroassist/` — чтение и обработка сигнала, вычисление признаков, воспроизведение/передача.
- `PythonServer/scripts/serve_demo.py` — запуск плейлиста покой → арифметика (по 40 с).

## Как устроено

EDF → обработка окон ЭЭГ в Python → вычисление признаков → `model.joblib` → JSON с `p_task` через `ws://127.0.0.1:8765` → Unity. Unity переключает режим **по прогнозу**, а не по известной метке записи. Границы: два последовательных окна с `p_task ≥ 0.68` для концентрации; два с `p_task ≤ 0.42` для полного режима. Между ними режим сохраняется. Ручное переключение отключает автоматику, пока пользователь не включит её вновь.

Важно: модель классифицирует **условия записи EEGMAT** (покой / арифметическая задача), а **не измеряет усталость** и не подтверждает снижение нагрузки от дизайна интерфейса.

## Источники данных

Реальные записи EEGMAT: [NEMAR nm000109](https://ww2.nemar.org/dataset/nm000109); первичная публикация: [PhysioNet EEG During Mental Arithmetic Tasks](https://physionet.org/content/eegmat/1.0.0/). Репозиторий содержит только короткие демонстрационные фрагменты, не полный исходный набор EEGMAT.

## Проверка

Запустите `RUN_TESTS.bat` после установки окружения. При проблемах: проверьте окно сервера, порт 8765, выбранную Unity-сцену, установку пакетов и доступность Python.

## Ограничения

- Интерфейс построен на UI Toolkit; приложения реализованы как интерактивные **учебные заглушки**, без доступа к реальной телефонной системе.
- Проверка компиляции и внешнего вида в Unity должна выполняться на машине с установленным редактором. Наличие исходников не эквивалентно подтверждённой работе проекта в чистом Unity.
- Модель была сериализована с конкретной версией scikit-learn; при предупреждении о несовпадении версий целесообразно воспроизвести окружение обучения (1.8.0) и повторно проверить предсказания.
