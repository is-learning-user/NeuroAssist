# NeuroAssist — дополнительный патч чёткости

Устанавливается **поверх NeuroAssist_Visual_Patch.zip** в существующий Unity-проект. Полный проект, иконки PNG и шрифты повторно не поставляются.

## Установка

1. Остановите Play. Сохраните резервную копию `Assets/NeuroAssist`.
2. Скопируйте содержимое `UnityProject/Assets/` из этого ZIP в `Assets/` вашего проекта с заменой файлов.
3. После импорта выберите **NeuroAssist → Sharpness → Use native Game View resolution** и снова нажмите Play. При первом импорте настройка также пытается примениться автоматически к уже открытым Game View.

В режиме Free Aspect масштаб Game должен стать **1x**. Проверьте результат и в обычной, и в развёрнутой вкладке.

Не удаляйте Library и не делайте Reimport All. Unity переимпортирует только иконки, настройки которых изменены, и перекомпилирует два скрипта. Новая сцена не требуется.

## Что исправляется

### Нативное разрешение вкладки Game

На присланных скриншотах указан Scale 1.3x, а ступенчатость видна одновременно на шрифтах, иконках и рамке. Это согласуется с увеличением кадра Game View при пониженном разрешении, но сам флажок Low Resolution Aspect Ratios на скриншотах не виден — причина пока не подтверждена измерением в вашем редакторе.

В Unity параметр Low Resolution Aspect Ratios уменьшает разрешение превью при эмуляции низкой плотности пикселей. Масштабирование готового кадра обратно не возвращает исходную детализацию. Патч отключает этот режим и устанавливает нативный масштаб 1x. Для фиксированного разрешения, превышающего размер окна, сохраняется Fit, чтобы не обрезать экран. Free Aspect и выбранное разрешение патч не меняет.

Изменяется только состояние открытых Game View текущего редактора. Параметры монитора и масштаб Windows не затрагиваются. Глобальные QualitySettings, URP Render Scale, камера и ProjectSettings не меняются: в приложенном проекте URP Render Scale уже равен 1, а UI использует отдельную экранную панель.

Тип GameView в Unity внутренний, поэтому редакторский помощник использует проверяемую reflection-обёртку. Если соответствующие члены API в вашей версии отсутствуют, скрипт выдаёт понятную инструкцию в Console; приложение продолжает работать. Автоматическую настройку через Unity 6.6 в этой среде проверить невозможно.

Ручной эквивалент команды: **Game → Free Aspect → снять Low Resolution Aspect Ratios**, затем **Scale 1x**. Если флажок заблокирован при плотности экрана 100%, это штатное поведение Unity; понижения HiDPI-разрешения в таком случае нет.

### Фильтрация уменьшенных иконок

В предыдущем патче 512-пиксельные иконки использовали Bilinear без mipmaps. На экране иконка может занимать всего 30–100 пикселей. При таком уменьшении одной билинейной выборки недостаточно для качественного усреднения мелких деталей.

Теперь для 13 используемых иконок включены mipmaps и Trilinear. Динамический атлас UI Toolkit обходит только `icon_*`, чтобы сохранить их собственные mip-уровни. Фоны и SDF-текст не исключаются этим фильтром. Исходные PNG не меняются, GUID в `.meta` сохранены. Пользовательские шейдеры и новые пакеты не добавлены.

Дополнительно повышен контраст второстепенных надписей. Размеры, сетки, отступы, интерактивность и логика EEG остались прежними. Увеличение памяти текстур из-за mipmaps составляет приблизительно треть их исходного несжатого объёма; исключение иконок из атласа может увеличить число переключений текстур.

## Если улучшение недостаточно

В Play выберите **NeuroAssist → Sharpness → Print rendering report**. Одна запись Console покажет:

- Screen и фактический targetRenderSize вкладки Game;
- lowResolutionForAspectRatios, backingScale и zoomAreaScale, когда API доступен;
- размеры, количество mip-уровней и фильтр нескольких иконок;
- параметры SDF-шрифтов и экранной UI-панели.

Для иконки 512×512 ожидаются 10 mip-уровней и Trilinear; для Game в Free Aspect — lowResolutionForAspectRatios=False и масштаб примерно (1, 1). Если настройки редактора не соответствуют этим значениям, повторите команду Use native Game View resolution.

Маленькая вкладка физически уменьшает весь макет: даже корректно отрисованный текст в 6–8 пикселей не будет столь же читаемым, как в развёрнутом Game. Этот патч исправляет выбор разрешения и фильтрацию, а не обещает одинаковую читаемость при любой высоте окна.

## Проверки и ограничения

Проведены синтаксический разбор C#, разбор USS, сравнение структуры со старой версией, проверка метаданных и GUID. Изменения USS ограничены цветами. В ZIP включены только изменения относительно первого визуального патча.

**Unity в среде подготовки не установлен. Компиляция, работа редакторской команды, фактическая фильтрация в Unity и итоговая резкость на вашем экране не проверены.** Наличие ожидаемых настроек и новый скриншот из Unity позволят подтвердить устранение причины.

Справочные источники Unity:
- https://docs.unity3d.com/ja/2023.2/Manual/GameView.html
- https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/GameView/GameView.cs
- https://docs.unity3d.com/cn/6000.0/ScriptReference/UIElements.DynamicAtlasSettings.html

## Откат

Верните из резервной копии `NeuroAssistUI.cs`, `NeuroAssistStyle.uss` и изменённые `.meta` иконок. Удалите `Editor/NeuroAssistSharpGameView.cs` вместе с его `.meta`. При необходимости верните прежний Scale и флажок Low Resolution Aspect Ratios вручную; удаление скрипта само по себе не меняет настройки уже открытой вкладки Game.
