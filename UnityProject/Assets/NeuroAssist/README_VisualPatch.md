# NeuroAssist — патч визуального интерфейса

Для приложенного проекта NeuroAssist_Layout_Fix и Unity 6.6 (6000.6.0f1).
Это патч Assets, а не новый Unity-проект.

## Установка

1. Остановите Play Mode. Сохраните резервную копию `Assets/NeuroAssist`.
2. Распакуйте ZIP в отдельную папку. Скопируйте содержимое `UnityProject/Assets/` из патча в папку `Assets/` **вашего существующего проекта**, подтвердив замену файлов. Не создавайте вложенный `Assets/UnityProject/Assets`.
3. Дождитесь импорта изменённых ресурсов и перекомпиляции скриптов. Откройте прежнюю сцену `NeuroAssist_Demo` и нажмите Play. Создавать сцену заново не нужно.

SDF-шрифты и настройки текста создаются редактором автоматически один раз. Если Console сообщает, что UI assets не готовы, остановите Play, дождитесь окончания импорта и выберите **NeuroAssist → Repair UI assets**, затем повторите Play.

Не удаляйте папку Library и не запускайте Reimport All: патч этого не требует. ProjectSettings, Packages, сцены, PythonServer, модель и записи EEG не входят в архив. При оценке резкости используйте Game Scale 1x либо размер, при котором редактор не растягивает уже отрисованный кадр.

## Что изменено

- `Scripts/NeuroAssistUI.cs`: переработанная иерархия UI Toolkit; явные строки 4×2 в полном режиме и 2×2 в концентрации; настоящие кнопки, страницы приложений и обратная связь о демодействиях.
- `Resources/NeuroAssistStyle.uss`: единая палитра, крупные плитки, карточки уведомлений, нижняя панель, рамка смартфона и спокойная диагностическая панель. Стандартные отступы, минимальные размеры и фоны Button сброшены явно.
- `Editor/NeuroAssistUIPanelBootstrap.cs`: создание двух TextCore SDF-атласов из локальных Noto Sans Regular/Bold и PanelTextSettings; сохранение существующего PanelSettings без изменения его GUID. Повторный запуск не пересоздаёт уже существующие шрифтовые assets.
- Отдельные иконки с плавными контурами: 512×512; статусные значки: 264×68. Иконки и небольшие декоративные фоны — самостоятельные ресурсы. Ни один экран не заменён картинкой.
- Настройки текстур: Bilinear, Clamp, без mipmaps и компрессии, без округления NPOT-размеров. Существующие GUID изменённых текстур сохранены; неизменённые `.meta` скриптов и USS намеренно не включены.
- В комплекте два неизменённых шрифта Noto Sans с кириллицей и лицензия `NotoSans-OFL.txt`. Новых Unity-пакетов и пользовательских шейдеров нет.

`NeuroAssistClient.cs` не изменён. Все чтения EEG и команды ручного/автоматического режима используют его прежний публичный API. Приложения сохраняют учебный характер: звонки, письма и демодействия не выполняют внешние операции.

## Масштабирование

Телефон имеет логическую рамку 414×874. Внутренний экран — 394×854. Масштаб панели выбирается по меньшему из доступных коэффициентов ширины и высоты; экран не растягивается независимо по осям и не переводится в RenderTexture.

В широком окне телефон и диагностика расположены рядом. Если отношение ширины к высоте меньше 1,04, диагностика открывается кнопкой в верхней панели и закрывается кнопкой «К телефону». Это сохраняет место для смартфона в узком Game View. Изменение размера окна обрабатывается во время Play.

На главных экранах, в диагностике и на демонстрационных страницах нет ScrollView. Подробности EEG заменяют поясняющий блок внутри диагностической панели, а не увеличивают её высоту. Чем меньше физический размер Game View, тем меньше физический размер текста: для визуальной оценки предпочтительна высота окна от 720 пикселей.

## Сопоставление с эталоном

| Элемент эталона | Решение в патче |
| --- | --- |
| Тёмная карточка рабочего телефона и восемь приложений | Карточка с аватаром, две строки по четыре приложения |
| Три отдельные карточки уведомлений | Иконка, время, заголовок и двухстрочный текст; каждая карточка нажимается |
| Светлая нижняя панель | Четыре интерактивных ярлыка и отдельный индикатор Home |
| Крупные приложения в концентрации | Две явные строки по две плитки, счётчики на сообщениях и почте |
| «Полный режим», объединённые уведомления, «Все приложения» | Три самостоятельных элемента с рабочими обработчиками |
| Светлая палитра и спокойная типографика | Голубовато-белые поверхности, синий акцент, два начертания SDF-шрифта |

Результат приближен по композиции и визуальной иерархии. Это не пиксельная копия: сохранены собственные иконки, учебная интерактивность и настоящая правая EEG-панель.

## Что фактически проверено

- C# разобран синтаксическим парсером без ошибок; это **не компиляция с Unity assemblies**.
- USS разобран CSS-парсером; дополнительно проверены используемые свойства. CSS-парсер **не заменяет импорт USS в Unity**.
- Проверены наличие текстур, разрешения, настройки импорта, покрытие кириллицы и используемых символов шрифтами, сохранение существующих GUID.
- В отдельной HTML-модели иерархии с переносом фактических USS-правил проверены полные экраны и режим концентрации при 1920×1080, 1440×1000, 1280×720, 960×540, 800×600, 600×800 и 390×844. В этой модели не обнаружены переполнение основных блоков и горизонтальный выход текста; четыре плитки сохраняют два ряда.
- В той же модели проверены каталог восьми приложений, шесть уведомлений, страница сообщений и развёрнутые сведения EEG в узком окне.
- Проверено, что ZIP содержит только изменённые и новые файлы под `UnityProject/Assets/`; EEG-клиент, сервер, модель, данные, сцены и настройки проекта в патч не попали.

**Unity здесь отсутствует. Компиляция, импорт SDF в Unity 6.6, фактический Unity-рендер, работа кликов в Play Mode и сквозная EEG/WebSocket-проверка не выполнялись.** Предварительная визуальная проверка выполнена по отдельной модели компоновки и не является скриншотом Unity или доказательством совпадения двух движков.

## Быстрая проверка после установки

1. Полный режим: восемь приложений, три карточки и четыре ярлыка нижней панели видны целиком.
2. Кнопка «Концентрация»: четыре плитки расположены 2×2; доступны «Полный режим» и «Все приложения».
3. Откройте приложение и вернитесь на главный экран. Нажмите демодействие: подтверждение появляется внутри телефона.
4. Включите ручной режим, затем «Вернуть автоматику»; при запущенном прежнем Python-сервере проверьте обновление вероятности и автоматическое переключение.
5. Откройте сведения EEG, измените размер Game View и разверните вкладку. В узком окне проверьте «Диагностика» → «К телефону».

## Откат

Верните резервную копию `Assets/NeuroAssist`. Новые шрифты и сгенерированные `NeuroAssistRegularSDF.asset`, `NeuroAssistBoldSDF.asset`, `NeuroAssistTextSettings.asset` не нужны старой версии; их можно удалить вместе с соответствующими `.meta`. Если сохраняете существующий `NeuroAssistPanel.asset`, после возврата старого bootstrap выберите Repair UI assets для восстановления его прежнего режима масштабирования.
